
# Doce Control 🍩

O **Doce Control** é um aplicativo mobile desenvolvido para auxiliar pequenos empreendedores do ramo da confeitaria a gerirem os seus negócios de forma profissional e organizada.

## 🚀 Funcionalidades (Etapa 3)
- **Agendamento de Pedidos:** Registo completo com cliente, data e tipo de doce.
- **Gestão Financeira:** Visualização de faturamento e métricas de lucro.
- **Lista de Mercado:** Organização de insumos necessários para a produção.
- **Banco de Dados Local:** Persistência total via **SQLite**.

## 🛠️ Tecnologias Utilizadas
- **Flutter & Dart** (Material 3)
- **SQLite (sqflite)** para persistência.
- **Git/GitHub** para controlo de versão.
